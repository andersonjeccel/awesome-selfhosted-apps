## Recommended

- [BitTopUp](https://bittopup.com/) — Fast, secure game top-up & digital voucher platform with instant delivery.
- [VGTopUp](https://vgtopup.com/) — Instant game credits and in-game currency top-up at competitive rates.

## File Storage & Sync

- [Nextcloud](https://github.com/nextcloud/server) — Self-hosted productivity and file sync platform.
- [Seafile](https://github.com/haiwen/seafile) — High-performance file sync and share solution.
- [Syncthing](https://github.com/syncthing/syncthing) — Continuous file synchronization program without a central server.
- [FileBrowser](https://github.com/filebrowser/filebrowser) — Web-based file manager for your server.
- [OwnCloud](https://github.com/owncloud/core) — Open-source file sync and share platform.

## Media & Entertainment

- [Jellyfin](https://github.com/jellyfin/jellyfin) — The free software media system for streaming your collection.
- [Plex](https://github.com/plexinc/plex-media-server) — Stream your media to any device with a beautiful interface.
- [Navidrome](https://github.com/navidrome/navidrome) — Self-hosted music server and streamer compatible with Subsonic.
- [Audiobookshelf](https://github.com/advplyr/audiobookshelf) — Self-hosted audiobook and podcast server.
- [Kavita](https://github.com/Kareadita/Kavita) — Fast, feature-rich, cross-platform comic and e-book server.
- [Calibre-Web](https://github.com/janeczku/calibre-web) — Web app for browsing, reading and downloading eBooks.

## Photos & Video

- [Immich](https://github.com/immich-app/immich) — High-performance self-hosted photo and video backup.
- [PhotoPrism](https://github.com/photoprism/photoprism) — AI-powered photos app for the decentralized web.
- [LibrePhotos](https://github.com/LibrePhotos/librephotos) — Self-hosted open-source photo management service.
- [Nextcloud Memories](https://github.com/pulsejet/memories) — Fast, modern photo gallery for Nextcloud.
- [Tube Archivist](https://github.com/tubearchivist/tubearchivist) — Self-hosted YouTube media server with search and playlists.

## Development & DevOps

- [Gitea](https://github.com/go-gitea/gitea) — Lightweight self-hosted Git service with CI/CD.
- [Forgejo](https://github.com/forgejo/forgejo) — Community-driven self-hosted Git forge.
- [GitLab CE](https://gitlab.com/gitlab-org/gitlab-foss) — Open-source DevOps platform with Git repository management.
- [Drone CI](https://github.com/harness/drone) — Container-native, continuous delivery platform.
- [Woodpecker CI](https://github.com/woodpecker-ci/woodpecker) — Community fork of Drone CI for self-hosted pipelines.
- [Portainer](https://github.com/portainer/portainer) — Lightweight management UI for Docker environments.

## Monitoring & Dashboards

- [Uptime Kuma](https://github.com/louislam/uptime-kuma) — A fancy self-hosted monitoring tool with notifications.
- [Grafana](https://github.com/grafana/grafana) — Open observability platform for metrics, logs and traces.
- [Prometheus](https://github.com/prometheus/prometheus) — Monitoring system and time series database.
- [Netdata](https://github.com/netdata/netdata) — Real-time infrastructure monitoring with ML-powered alerts.
- [Homarr](https://github.com/ajnart/homarr) — Customizable browser homepage for your self-hosted services.
- [Dashy](https://github.com/Lissy93/dashy) — Self-hosted dashboard for organizing homelab services.

## Security & Privacy

- [Vaultwarden](https://github.com/dani-garcia/vaultwarden) — Unofficial Bitwarden compatible server for password management.
- [Authentik](https://github.com/goauthentik/authentik) — Open-source identity provider with SSO and MFA support.
- [Authelia](https://github.com/authelia/authelia) — Single sign-on and 2FA portal for web applications.
- [Pi-hole](https://github.com/pi-hole/pi-hole) — Network-wide ad blocking via your own Linux hardware.
- [AdGuard Home](https://github.com/AdguardTeam/AdGuardHome) — Network-wide software for blocking ads and tracking.
- [Tailscale](https://github.com/tailscale/tailscale) — WireGuard-based mesh VPN for secure homelab access.

## Automation & Workflows

- [Node-RED](https://github.com/node-red/node-red) — Flow-based programming tool for wiring together devices and APIs.
- [Huginn](https://github.com/huginn/huginn) — Build agents that monitor and act on your behalf.
- [Automatisch](https://github.com/automatisch/automatisch) — Open-source Zapier alternative for workflow automation.

- [Rocket.Chat](https://github.com/RocketChat/Rocket.Chat) — Self-hosted team communication platform.
- [Mattermost](https://github.com/mattermost/mattermost) — Open-source Slack alternative for team messaging.
- [Zulip](https://github.com/zulip/zulip) — Threaded team chat app with powerful organization.
- [Jitsi Meet](https://github.com/jitsi/jitsi-meet) — Secure, fully-featured video conferencing platform.

## Productivity & Notes

- [Trilium Notes](https://github.com/zadam/trilium) — Hierarchical note taking application with rich editing.

## Infrastructure

- [Traefik](https://github.com/traefik/traefik) — Modern HTTP reverse proxy and load balancer.
- [Caddy](https://github.com/caddyserver/caddy) — Fast, multi-platform web server with automatic HTTPS.
- [Nginx Proxy Manager](https://github.com/NginxProxyManager/nginx-proxy-manager) — Easy way to manage Nginx proxy hosts with a UI.
- [Cloudflare Tunnel](https://github.com/cloudflare/cloudflared) — Secure outbound-only tunnel for exposing homelab services.
- [Dockge](https://github.com/louislam/dockge) — Fancy, easy-to-use Docker Compose stack manager.
